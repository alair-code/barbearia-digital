# Barbearia Digital

Template comercial de site profissional para barbearias, desenvolvido em HTML5, CSS3 e JavaScript puro.

## Estrutura

- `index.html` — página principal
- `css/estilo.css` — identidade visual e layout
- `css/responsivo.css` — adaptações para mobile e tablet
- `js/configuracao.js` — dados que devem ser personalizados por cliente
- `js/principal.js` — conteúdo dinâmico e comportamento geral
- `js/menu.js` — menu responsivo
- `js/galeria.js` — lightbox da galeria
- `js/depoimentos.js` — carrossel de depoimentos

## Personalização

Comece por `js/configuracao.js`. Altere nome, telefone, WhatsApp, e-mail, endereço, redes sociais, agendamento e nome do desenvolvedor.

Serviços, preços, profissionais e imagens demonstrativas ficam organizados em `js/principal.js` para facilitar a criação de novas versões.

As cores principais estão centralizadas no início de `css/estilo.css`.

## Imagens

A primeira versão usa imagens remotas demonstrativas. Para um cliente real, substitua as URLs por imagens próprias/otimizadas e mantenha os textos alternativos.

## Tecnologias

HTML5 + CSS3 + JavaScript puro. Não há backend ou banco de dados nesta primeira versão. O botão de agendamento e WhatsApp são preparados para links externos.
